# 代码航站 v0.2.0

代码航站的首次发行。解压后打开做题器.html即可使用，无需账号或服务器。

## 下载

- code-station-v0.2.0.zip：普通用户发行包，附可选示例题库。
- code-station-demo-v0.2.0.zip：独立示例题库，解压后导入其中的JSON。
- code-station-source-v0.2.0.zip：可独立构建的源码及生成页面。
- runtime-corresponding-source.zip：内嵌编译器及运行组件的对应源码、修改和重建说明。
- SHA256SUMS.txt：以上文件的校验值。

## 功能

- 导入和管理JSON题包，支持单选、多选、普通填空、程序填空、改错和编程。
- 整卷练习可选即时批改或交卷后批改；模拟考试限时作答，交卷后统一判分。
- 复习计划、学习统计、历史答卷、本机代码编辑和C程序运行。
- 默认与航天两套界面、字号和动效设置、答对后自动跳题。
- 题库、学习记录和代码草稿分别备份；升级保留当前浏览器的数据。

示例题库为独立编写的27题、5套试卷，包含两张插图与连续小问，非考试真题。HTML本身不内置题目，使用者自行选择是否导入示例。

## 验证与边界

已通过六题型、真实WASM编译运行、整卷与模拟考试、导入和备份、存储异常及升级保数据检查。已在Windows桌面Edge验证；窄屏检查为桌面模拟，不代表所有手机和浏览器已实测。

模拟考试当前不包含编程题。编程提交按题包公开用例判分，通过用例不代表覆盖所有可能输入。题库与记录只保存在当前浏览器，换浏览器、移动文件或清理数据前请先备份。
