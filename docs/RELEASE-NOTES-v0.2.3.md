# 代码航站 v0.2.3

本次更新改善本机 C 程序的运行正确性，扩展 long double 精度，并减少一次提交多个测试点时的重复准备。适合继续使用现有题包进行日常练习和模拟考试。

## 改进与修复

- 修复含 64 位整数、结构体成员和二维数组动态下标的部分程序可能被误判的问题，并修正相关乘法和浮点转整数边界。
- long double 扩展为 128 位浮点格式，改进相应常量、基本运算、转换和输入输出；修正十六进制浮点格式输出。
- 补齐 rewind、setbuf、vfscanf、putc、fgetpos、fsetpos、perror 等常见接口，改善文件定位、删除、改名和标准输入输出重定向。
- 改善静态内联函数、局部变量对齐，以及结构体和联合体可变参数的运行行为。
- 同一次提交复用编译与运行准备结果；各测试点仍使用独立的内存、文件和运行状态。

## 如何升级

升级前分别备份题库、学习记录和代码草稿。解压新版发行包，在原位置替换「做题器.html」，用同一浏览器打开即可继续使用已有记录。更换浏览器或文件位置时，先恢复题库，再导入学习记录与草稿。

题包格式和学习记录格式沿用现有版本，无需修改普通题包。旧有 long double 程序可能因精度提高而得到不同的末位输出；自行编写题包时，请按题目要求设置输出格式并核对预期结果。

## 使用提醒

本工具面向教学练习和受支持范围内的 C 程序。完整数学函数、复数、宽字符、多语言 locale、浮点环境和部分较新语言能力仍有缺项。遇到接口不可用或运行结果异常，可通过项目 Issues 提供最小源码、输入和预期输出。

编程题按题包提供的用例判分。通过这些用例，表示满足已检查的输入范围。
