# 代码航站 0.2v

代码航站是本机离线运行的编程练习工具，支持题包导入、练习、模拟考试、复习、统计及C程序自测。无需注册账号，不调用模型API。

## 开始使用

1. 解压整个发行包，双击“做题器.html”。建议使用较新的桌面版Edge或Chrome。
2. 在“导入 / 管理题包”中选择JSON题包，检查预览后确认导入。可先使用随附“示例题包/示例题库.json”体验，也可导入其他有权使用的题库。页面不预装题目；Word、PDF和ZIP不能直接当题包导入。
3. 选择试卷及练习方式。整卷练习可选择即时批改或交卷后批改；模拟考试交卷后统一判分。
4. 顶部“?”可查阅完整使用说明。界面风格、字号、动效及自动跳题可在设置中调整。

## 保存与备份

题库、学习记录和代码草稿保存在当前浏览器，需要分别导出备份。复制HTML不包含这些数据；换浏览器、清理数据或移动文件前请先备份。升级时建议在原位置替换HTML，正常升级保留记录。
