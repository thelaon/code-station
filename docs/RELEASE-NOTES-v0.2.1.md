# 代码航站 v0.2.1

模拟考试现在可以纳入编程题。题库也可以逐题审阅和修改，发现错字、答案或用例有问题时，可直接在题库管理中更正。

## 模拟考试支持编程题

- 新开的模拟考试按试卷实际题型和分值组卷。编程代码随答卷保存，作答时可用自定义输入查看程序输出，交卷后统一批改。
- 可以手动交卷，也会在到期时收卷。如果关闭页面期间到期，重新打开原页面会按保存的答卷自动交卷。批改时间不计入作答用时。
- 若批改暂时失败，答卷会锁定并保留。回到答卷点击「重试批改」即可继续。
- 成绩页显示编程题得分、用例通过数、编译错误、运行超时和未作答状态。全部判分用例通过才得该题满分。可从「统计 → 考试成绩」回看提交代码。

## 题库可以逐题校对

在「题库管理」中选择或粘贴 JSON 题包，检查通过后点「审阅题目」。可以按试卷、题型查找，修改题干、选项、答案、解析，以及编程题的样例和判分用例。改好后先应用到待导入题包，再确认导入。

已导入的题包也可以打开审阅。若修改会使旧作答或分数失效，保存前会提示，并要求确认是否清除该题库的关联记录。建议先备份旧题包和学习记录。

## 练习与统计更方便

- 窄屏可在题目和答题卡之间快速跳转。做题页重新排列了题号、进度和计时。
- 编程练习可以把题面样例一键填入自测，并按用例展开对照实际输出和预期输出。
- 复习页更容易看清当前复习范围和到期题量。统计页可点选近 7 天中的日期，也可按年份和月份浏览历史作答次数。
- 修复放弃考试或延后批改的整卷练习后，刷新页面仍恢复旧答卷的问题。

## 从 v0.2.0 升级

现有 JSON 题包可继续使用。升级前建议分别备份题库、学习记录和代码草稿，再在原位置替换「做题器.html」，用同一浏览器打开。旧版已开始的考试会沿用原题单、作答和截止时间，新开的考试才会纳入编程题。

如果换了浏览器或文件位置，请先恢复题库，再恢复学习记录，代码草稿可单独恢复。首次体验可导入随附的「示例题包/示例题库.json」。
