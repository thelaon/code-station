# 版权与发布范围讨论（2026-10-30）

框架、自有代码与题库分别处理，目前不为整个项目新增统一开源许可。仓库私有保存与对外分发是不同事项；向朋友免费提供材料也不能直接视为已取得题库转发授权。

| 对象 | 已有材料 | 仍需补齐 |
| --- | --- | --- |
| 界面与业务代码 | 独立构建源码和修改历史 | 检查来源、作者贡献及可许可范围，再决定自有部分许可 |
| TCC | 当前WASM与LGPL 2.1许可文本 | 对应上游版本、修改源码、构建工具与步骤、二进制映射；依据实际组合方式核对替换/重链接安排 |
| WABT | Apache 2.0许可及现有注释 | 对应版本、修改说明与上游NOTICE（如有） |
| libc、头文件、运行桥 | 已冻结资源与指纹 | 逐文件来源/许可清单和对应源码构建链 |
| 第三方考试题库 | 私人来源材料及审查记录 | 分别核对题干、图片、解析和汇编的权利与授权，不以转JSON或重新裁图代替授权 |

本轮检查得到的是“可独立构建应用”，不等于“可从源码重建内嵌编译器及libc”，也不等于许可补证已经完成。第三方题库材料不在本仓库。新编译器候选仍在隔离目录推进，不替换已验收vendor。

建议下一步由编译器工作输出组件来源、版本、原许可证、修改、源码、构建步骤及产物SHA对应表；总控再核对交付方式。自有代码的整体许可选择留待来源核对之后。

核对依据：[国家版权局《著作权法》](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)第3、10、13、15、24条；[GNU LGPL 2.1正文](https://www.gnu.org/licenses/old-licenses/lgpl-2.1.html)第4、6节及[GNU FAQ](https://www.gnu.org/licenses/gpl-faq.en.html#LGPLStaticVsDynamic)；[Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0)第4节。这里据当前材料列出待办，不作整个产品或具体题目权属已完成认定。
