# 代码航站 v0.2.2

离线 C 编程练习和模拟考试支持按文件内容判分。使用变长数组或较大局部数组的 C 程序也更容易在做题器中运行。

## 新功能

- **支持文件读写题。** 在「题库管理」导入带文件用例的 JSON 题包后，可以在编程练习中自测，也可在整卷练习或模拟考试交卷后自动判分。每个用例会加载题包提供的输入文件，并按字节核对题目指定的输出文件。
- **支持 C 变长数组。** 可以用运行时读入的尺寸声明局部数组。程序可使用的栈空间增至 2 MiB，超限时会在自测或成绩中显示原因。

## 体验改进与问题修复

- 缩短了反复读写较大文件和批量复制、移动、填充内存的运行时间。
- 修复了连续读取同一文件、追加写入、长格式输出和退出时刷新文件的问题。
- 支持用 `scanf`、`sscanf` 和 `fscanf` 的 `%[...]` 读取一组字符。混用 `scanf`、`getchar`、`fgets` 时，各函数会从同一输入位置继续读取。
- 修复了整数转换超出取值范围时的结果和错误提示。浮点输出改进了舍入和格式化，`%F` 会以大写显示 `INF` 和 `NAN`。

## 如何升级

从 v0.2.1 升级前，建议分别备份题库、学习记录和代码草稿。用新版「做题器.html」替换原位置的文件，并用同一浏览器打开，即可继续使用已有记录。更换浏览器或文件位置时，先恢复题库，再导入学习记录和代码草稿。

## 使用提醒

文件题的输入与预期输出由 JSON 题包提供。要修改文件用例，请编辑题包 JSON。用例结束后，程序产生的临时文件会释放。
