# 做题器框架 · 发布准备

离线使用的做题器框架，提供题包导入、普通练习、模拟考试、复习、统计、题库管理及C程序运行。双击“做题器.html”打开；所有操作在本机完成，不需要账号、服务器或模型API。

本目录不含预装题目、参考答案、解析、题目图片或示例题库。使用者需另外准备有权使用的JSON题包，在“导入 / 管理题包 → 导入 / 更新题包”中检查、预览并确认导入。Word、PDF和ZIP不直接识题。

题库与学习记录保存在浏览器。迁移时分别导出题库备份、学习记录及代码草稿，先恢复题库，再恢复记录。模拟考试支持客观题和程序填空/改错；编程题在普通练习中提交公开用例。框架使用独立存储；新构建首次打开会按当前约定清空框架自身记录，同一构建刷新保留。

这是未来发布内容的独立储存目录，当前仅包含成品和必要说明；未包含依赖私人题源的构建工程，也不沿用私人仓库提交历史。当前阶段用于私有归档，不自动公开发布或授予统一开源许可。第三方组件与许可见“第三方组件说明.md”和licenses目录。
