## 编程题参考代码

```c
#include <stdio.h>
int main(void) {
    int a, b;
    if (scanf("%d%d", &a, &b) != 2) return 0;
    printf("%d", a + b);
    return 0;
}
```

改错题须保留行数，并为修改行添加注释。字符编码题的两组用例分别为“苏A → 3 苏A”“沪B → 3 沪B”。
