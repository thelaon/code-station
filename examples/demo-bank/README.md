# 示例题库

供代码航站 v0.2.1 体验和功能检查使用，为独立编写的示例。导入一次即可添加 5 套试卷、27 道题，两张插图已包含在 JSON 中。

## 使用

打开做题器，在“导入 / 管理题包”中选择本目录的“示例题库.json”，检查预览后确认导入。首页左侧选择“示例题库”，即可切换试卷和练习方式。无需导入README、LICENSE或参考答案文件。

| 试卷 | 内容 | 题数 | 练习满分 |
| --- | --- | ---: | ---: |
| 基础题型 A 卷 | 单选、多选、文本/数值填空、电路图 | 10 | 20 |
| 可变选项 B 卷 | 2至8个选项，多选含一个或多个正确项 | 7 | 14 |
| 连续小问 C 卷 | 共用材料、配图、连续小问和独立题 | 6小问/题 | 12 |
| 程序练习 D 卷 | 程序填空、改错、整数求和编程 | 3 | 6 |
| 字符编码 E 卷 | GBK字符串字节数与中文输出 | 1 | 2 |

每题2分，多空题均分；多选须全选且无错选。连续小问单独计分，前两道为独立题，小问编号显示为3(1)、3(2)、4(1)、4(2)。试卷不标年份，在首页“无年份”分组中显示。分值只用于体验，不代表真实考试评分标准。

v0.2.1 新开的 D 卷模拟考试包含编程题，共 3 题、满分 6 分，与整卷练习一致。v0.2.0 已开始的模拟考试沿用原题单。

## 建议检查顺序

1. A卷：查看电路图；试一次多选漏选、填空只答对一空及数值容差。
2. B卷：点击较后位置的选项；检查A—H快捷键及多选取消。
3. C卷：查看共用材料和配图，确认答题卡小问连续排列。
4. D卷：完成程序填空，按题面改错；编程题运行样例后提交。
5. E卷：按题面修正输出，运行“苏A”和“沪B”两组用例，预期均输出3字节和原字符串。
6. 尝试整卷即时批改、交卷后批改和模拟考试，再查看复习与统计；最后导出题库及学习记录。

参考答案另见“参考答案.md”。导入或练习会在本机产生记录，可在题库管理中停用或删除这份示例。
